# SportsSphere

SportsSphere is a full-stack sports slot booking platform built with React, Node.js, Express, and MongoDB. Users can browse sports, book available slots, view their bookings, cancel reservations, and avoid duplicate bookings. It also includes JWT authentication and an admin dashboard where admins can add sports, add slots, view all bookings, and activate or deactivate sports.

**Live Demo:** [link](https://sports-sphere-gamma.vercel.app)
**Backend API:**[link](https://sportssphere-api.onrender.com/)
**Tech Stack:** React, Vite, Node.js, Express, MongoDB, Mongoose, JWT, Axios

## Features

* User authentication with JWT
* Sports slot booking and cancellation
* Duplicate booking prevention
* My Bookings page
* Admin dashboard
* Add sports and slots
* View all bookings
* Activate/deactivate sports
